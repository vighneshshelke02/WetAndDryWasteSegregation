# 🚮 Wet and Dry Waste Segregation System using Arduino

This project automates the segregation of wet and dry waste using an Arduino. The system uses sensors to differentiate between the types of waste, and it triggers a mechanism to separate them accordingly.

## 🧰 Components Used
- Arduino Uno/Nano
- Ultrasonic Sensor (for waste detection)
- Servo Motors (for mechanism)
- Sensors (for detecting wet/dry waste)
- Jumper Wires
- Breadboard

## ⚙️ How It Works
1. The system uses ultrasonic sensors to detect waste and its type.
2. Depending on the type of waste (wet or dry), a servo motor moves the waste into the correct compartment.
3. Wet waste is stored in one container, and dry waste is stored in another.
